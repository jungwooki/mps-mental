# 성장 × 멘탈 통합 리포트 v4

## 원문 확인

사용자가 제공한 `초등학교 운동선수 체력훈련 지원 지침서.pdf`를 이 폴더에 복사했다. 본문 제목은 「유소년 체력 훈련 지원 지침서」이다. PDF는 두 쪽 펼침 구성으로, PDF 페이지와 책의 인쇄 쪽수가 다르다.

| 자료 | 책 쪽수 | PDF 페이지 | 적용 |
|---|---:|---:|---|
| 표 2-5 성장단계별 심리적 특징 | 46 | 24 | 인지·정서·사회 관점에서 보호자 대화와 관찰 방향 구성 |
| 그림 2-7 조기성숙과 늦은 성숙 | 47 | 24 | 같은 또래의 성숙 차이, 비교 부담, 개별 피드백의 필요성 |
| 표 2-6 사회적·심리적 나이 | 47 | 24 | 신체·기술·심리·사회 발달을 하나의 나이로 환산하지 않는 구조 |
| 표 2-12 장기 체력 발달구분 | 71 | 36 | 균형·협응·동작 기술에서 개인별 전문화로 이어지는 훈련 관점 |

`guide-page-24.png`와 `guide-page-36.png`는 위 페이지를 원본 PDF에서 렌더링한 검토용 이미지다. 원문 표의 행·열을 시각적으로 확인했다.

추가 확인: [IOC consensus statement on youth athletic development (2015)](https://pubmed.ncbi.nlm.nih.gov/26084524/). 성장·성숙·행동발달의 개인차를 고려하는 통합 지원 원칙을 보조적으로 확인했다. 원문 표의 학교급→MPS 5단계 연결, 6개월 기준 또는 특정 3지표의 타당성을 이 논문이 검증한 것으로 표현하지 않는다.

## 사용자 요청으로 적용한 연결

| 원자료 성장단계 | PHV 대조 | 리포트 이름 | 표 2-5 지도 참고 |
|---|---|---|---|
| Pre-PHV | PHV -2 | 급성장 이전 | 초등학교 |
| Stage 1 | PHV -1 | 가속기 | 초등학교 |
| Stage 2 | PHV 0 | 급성장기 | 중학교 |
| Stage 3 | PHV 1 | 감속기 | 중학교 |
| Stage 4 | PHV 2 | 종료기 | 고등학교 |

이 연결은 사용자가 요청한 리포트 설계 원칙이다. 원문이 5단계에 따른 심리 나이 환산을 제안한 것은 아니다. 리포트에서 '학교급별 특징을 성장단계에 연결한 지도 참고'임을 밝힌다. 학교급별 부정적인 일반화를 개인에게 붙이지 않고, 실제 관찰과 대화를 위한 질문으로 재구성했다.

표 2-12의 장기 체력 발달은 역연령, 성숙과 저항운동 기술 역량을 함께 제시한다. 이를 참고해 기초 움직임·균형·협응·코어·동작 숙련도·개별 훈련 방향을 제시했다. MPS Stage 번호를 Tanner Stage로 간주하지 않으며 성장단계만으로 훈련 중량·강도·기간을 정하지 않는다. 실제 체력 수행검사 결과가 없는 상태에서 체력 나이·기술 나이·심리적 나이를 산출하지 않는다.

## 결합과 검수

- 기존 v3 HTML의 749건과 멘탈 원점수·8유형·P/R/I를 유지했다.
- `~/Downloads/mps-authoring-inputs (1)~(4).xlsx`를 이름·성별·생년월일·측정일로 대조하고 MGI 및 기존 멘탈 세부 점수도 일치 확인했다.
- 성명·생년월일·성별 조합은 748개다. 749는 기록 수이며 고유 선수 수로 표현하지 않는다.
- 골연령은 AN열(년), AO열(개월), 성장단계는 AR열, PHV는 Y열을 사용했다. 원본 파일과 행을 검수 CSV에 남겼다.
- 실제 나이는 측정일 기준 달력의 완성 월수에 다음 월 기념일까지의 경과 비율을 더한다. 골연령 총개월 − 실제 나이 총개월 ≤ −6이면 '만숙형' 지원을 적용한다. 반올림한 표시값으로 분류하지 않는다.
- 6개월 기준은 사용자 지정 MPS 지원 기준이다. 의학적 만숙·질환 진단 기준이나 검증된 심리 위험 절단값으로 제시하지 않는다.
- 만숙형 144건은 실수 후 회복력, 실패 후 회복력, 외부평가 독립성의 실제 점수를 각각 강조한다. 세 지표를 임의의 새 종합점수로 합치지 않는다. 4.8 이상도 중점 표시하되 강점 유지로 설명한다.
- `Stage / PHV` 불일치 4건은 성장단계별 분류와 학교급 연결을 보류한다. 골연령이 유효하면 만숙형 판단 자체는 별도로 가능하다.
- 골연령 1세 1개월 1건은 원자료 재확인 대상으로 표시하고 골연령차와 만숙형 판단을 보류한다. 원자료를 추정해 수정하지 않는다.
- 기술적 이상 입력 검수: 골연령 년·개월의 정수성, 개월 0~11, 총개월 48~240, 실제 나이와 차이 절댓값 48개월 이내. 이 범위는 자동 보고 보류용 입력 검수이며 임상적 정상 범위가 아니다.
- 보호자에게 보이는 체격 정보는 키·체중이다. 신체 상태에 대한 설명은 관찰·상담 방향이며 실제 체력 측정 결과로 가장하지 않는다.
- 비교는 같은 성장단계의 기록 평균으로 통일한다. 전체 평균 및 성장단계를 섞은 동유형 평균은 리포트 비교선으로 사용하지 않는다.
- 유효 성장단계 745건: 급성장 이전 248건, 가속기 275건, 급성장기 177건, 감속기 42건, 종료기 3건. 단계·PHV 불일치 4건은 모든 단계 평균에서 제외하고, 해당 기록의 평균과 차이 및 레이더 비교선을 보류한다. 골연령 이상 1건은 단계·PHV가 일치하므로 확인된 단계에 포함하며, 골연령차 판단 보류는 유지한다.
- 평균은 본인 기록을 포함한 기록 단위 산술평균이다. 각 지표의 유효 수치만 사용한다. 차이는 `아이 원점수 − 같은 성장단계 평균`을 반올림 전에 계산하여 소수 둘째 자리까지 표시한다. 성별·역연령·멘탈 유형·만숙 여부는 추가 보정하지 않으며 규준·백분위·진단으로 표시하지 않는다. 10건 미만의 단계는 소표본으로 표시한다.
- 종합 MGI, 5대 지표, 회복 3지표에 같은 비교 기준을 적용한다. 웹의 상세 영역에서는 5단계별 평균과 차이를 나란히 확인할 수 있다. 다른 단계 평균은 자료 분포 참고이며 성장 목표 점수로 제시하지 않는다.
- v3의 8유형 유사도 수치와 유형별 선수 3명씩(총 24명)의 연결·사진·설명을 복원했다. 선수 사진은 기존 로컬 자산을 사용한다. 사용자 요청에 따라 카드의 사진 출처·라이선스 표시를 삭제했으며, 원본 출처 메타데이터와 사진 자료의 출처 파일은 유지한다. 예시는 실제 선수 심리검사 결과가 아니라 기존 v3의 경기 스타일 설명을 유지한 것이다.

사용자는 검수 예외를 '확인 필요로 표시하고 진행'하도록 확인했다.

## 페이지 구조

1. 성장 시기 × 멘탈 포지션: 골연령차·현재 체격·5단계 성장 흐름, 8유형 유사도 막대, 해당 유형의 선수 3명 카드. 보호자가 볼 세 질문은 웹 상세 영역에 보존한다.
2. 5대 지표 레이더와 파스텔 막대그래프: 레이더 점선은 같은 성장단계 평균이다. 막대는 중앙선을 평균(차이 0점)으로 두고 원점수 − 단계 평균의 차이를 좌우로 표시한다. 현재 점수·평균·차이 수치는 함께 표시한다. 회복 3지표는 각각 6점 대비 현재 점수의 원형 그래프와 평균 눈금, 점수 차이를 보여주며 만숙형 강조를 유지한다.
3. 8대 세부지표: 같은 성장단계 평균과 같은 만 나이 평균을 각각 파스텔 막대로 비교하고, 우측에는 직전 측정 대비 향상·유지·저하 상태를 표시한다.
4. 현재 성장단계에 맞춘 피지컬 관점과 보호자 대화: 기존 3페이지를 이동했다. 인지·정서·사회 특징을 행동으로 연결하고 다음 상담 기록을 안내한다.

기존 v3는 보존한다. 현재 파일은 `MPS_멘탈포지션_성장통합_A4_4페이지_v4.html`이다. 이전 링크 유지를 위해 `MPS_멘탈포지션_성장통합_A4_3페이지_v4.html`에도 동일한 4페이지 내용을 생성한다.

## 파스텔 막대와 원형 그래프 개편

사용자가 제공한 `SportsMPS_김해온(샘플).pdf`의 1·2페이지를 로컬에서 렌더링해 시각적으로 확인했다. 파스텔 막대·평균 표시선·원형 점수 표현을 참고했으며 PDF의 피지컬 점수는 멘탈 리포트에 적용하지 않았다.

- 5대 지표의 표를 막대 비교로 바꾸었다. 중앙은 같은 성장단계 평균이며 음수는 왼쪽, 양수는 오른쪽으로 표시한다. 전체 749건에 동일한 −5~+5점 눈금을 사용한다. 이 범위는 1~6점 척도에서 가능한 차이 범위이며 백분위가 아니다.
- 원형의 채워진 길이는 현재 점수/6이다. 중앙에는 점수와 `/6점`을 표시한다. 짧은 회색 눈금은 같은 성장단계 평균/6의 각도이다.
- 단계 미확인 기록은 비교 막대·평균선·원형 평균 눈금을 표시하지 않는다. 현재 점수와 원형 점수 자체는 유지한다. 레이더와 8유형 선수·유사도는 보존한다.
- 비교 수치, 막대 방향·길이, 원형 비율, 749건의 레이아웃과 이미지 로딩을 검수한다. 브라우저의 CSS 수치 직렬화 반올림은 0.0001%p 이내 오차를 허용하며 원래 차이값은 별도로 대조한다.

## 8대 세부지표와 또래 비교 (4페이지 개편)

새 3페이지는 경기 안정성, 경기 중 감정 조절, 외부평가 독립성, 자기주도 학습능력, 이미지트레이닝 활용능력, 주위 적응 및 활용 능력, 실패 후 회복력, 훈련 태도 지수를 표시한다. 첫 5대 지표와 별개인 8개 지표다.

- 또래 집단: 측정일 기준 같은 만 나이. 예를 들어 만 11세는 만 11세 생일부터 만 12세 생일 전까지이며 출생연도·학년만으로 묶지 않는다.
- 성장단계와 또래는 별개의 비교 집단이다. 나이와 성장단계 조건을 교집합으로 적용하지 않는다. 성장단계 비교에서 나이·성별을, 또래 비교에서 성장단계·성별을 추가 보정하지 않았다.
- 각 지표의 유효 1~6점 값만 평균 계산에 포함하고 실제 지표별 건수를 표시한다. `주위 적응 및 활용 능력`이 없는 기존 241건은 해당 지표에서만 제외한다. 미측정은 0점으로 바꾸지 않는다.
- 유효 비교 기록이 2건 미만이면 해당 평균·차이·막대를 보류한다. 2~9건은 소표본을 명시하고 참고 비교로 표시한다. 현재 전체 나이 집단: 만 8세 2건, 9세 11건, 10세 94건, 11세 243건, 12세 267건, 13세 120건, 14세 9건, 15세 2건, 16세 1건. 각 지표 유효 건수는 이보다 작을 수 있다.
- 오른쪽 상태는 평균과의 차이가 아닌 직전 개인 원점수와의 증감이다. 증가 `향상`, 동일 `유지`, 감소 `저하`. 임상적 유의성이나 효과 판정이 아니다.
- 이전 기록은 차트번호·성명·생년월일·성별이 모두 일치하는 더 이른 측정 중 가장 최근 기록을 사용한다. 같은 날짜의 점수가 충돌하거나 검사 버전이 다르면 보류한다. 이름·생년월일·성별은 같지만 차트번호가 다른 2건을 자동 연결하지 않았다.
- 현재 749건과 원본 4개 입력 파일에서 확실하게 연결 가능한 이전 측정은 없었다. 따라서 실제 리포트에는 `이전 기록 없음`을 표시한다. 실제 첫 검사가 확정된 것은 아니므로 `첫 측정`으로 단정하지 않는다. 과거 측정을 추정하거나 가상 자료를 실제 이력에 넣지 않는다.
- 별도 가상 샘플은 4회차 이력과 예시 평균으로 향상·유지·저하, 만 나이 변경을 보여준다. 기존 지원 페이지와 국기는 샘플의 4페이지로 이동했다.

공통 3페이지 구성은 `scripts/mental_detail_page.html`, 스타일은 `scripts/mental_detail.css`, 계산·렌더링은 `scripts/mental_detail_charts.js`를 사용한다. 두 빌더가 이를 HTML에 내장하므로 파일을 직접 열어도 작동한다.
